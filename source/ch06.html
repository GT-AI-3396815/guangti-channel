P0 宇宙线天体物理 重大发现

LHAASO认证天鹅座X-3为银河系最强宇宙线加速器，粒子能量达30 PeV

中国科学院高能物理研究所LHAASO（拉索）团队联合上海交通大学李政道研究所、上海天文台等机构，确认天鹅座X-3（Cygnus X-3）双星系统是迄今为止已知能够产生最高能量的粒子加速器。该黑洞或中子星通过疯狂吸积大质量伴星吹出的强烈星风，将粒子加速至至少30 PeV（1 PeV = 10^15电子伏特），远超当前主流理论预期。相关成果于2026年7月22日发表于《国家科学评论》（National Science Review）。

拉索测到超高能（>0.1 PeV）伽马信号具有明显的爆发现象，与费米伽马射线空间望远镜在GeV波段的观测存在显著时间关联。信号呈现4.8小时周期性，清晰显示双星绕转轨道效应，由此将加速器定位于约3个太阳半径尺度内——这是对宇宙中超高能粒子加速器的最高定位精度。这一发现标志着超高能时域天文学新领域的开启。

共同通讯作者包括曹臻研究员、李骢副研究员、王界双副教授、周佳能副研究员和Felix Aharonian教授。该成果已引起国际天体物理领域高度关注，成为专业会议上讨论最热烈的话题之一。

关键认知价值：这是人类首次以亚太阳半径精度锁定宇宙线源天体，30 PeV的粒子能量远超当前理论模型预测上限，表明黑洞或中子星附近的极端物理过程可能比此前认知的更加剧烈。这一发现为理解宇宙线起源这一百年之谜提供了关键证据，同时开辟了超高能时域天文学这一全新研究方向，对未来多信使天文学（电磁波+中微子+引力波）研究具有重要启示。

P0 太空望远镜 即将发射

NASA罗曼太空望远镜完成推进剂加注，定于8月30日发射升空

NASA南希·格雷斯·罗曼太空望远镜（Nancy Grace Roman Space Telescope）已进入发射倒计时。7月25日，工作团队在肯尼迪航天中心"有效载荷危险物处理设施"内完成了290加仑（约1098升）肼燃料加注。7月29日项目团队在戈达德太空飞行中心召开新闻发布会，确认这台造价40亿美元的旗舰望远镜将于8月30日由SpaceX猎鹰重型火箭发射升空，发射时间定为美国东部时间上午7时26分。

罗曼望远镜将前往距地球约150万公里的日地拉格朗日L2点——与詹姆斯·韦伯太空望远镜相同的引力稳定区域。与哈勃和韦伯不同，罗曼的核心优势在于宽视场巡天：其视场是哈勃的100倍，将在红外波段以前所未有的规模扫描数十亿颗恒星和星系，同时寻找隐藏的系外行星并探测暗物质和暗能量的性质。

NASA局长表示罗曼的加速发展是"公共投资、机构专业知识和私营企业携手合作"的成功案例，比原计划提前了整整九个月。

关键认知价值：罗曼望远镜代表天文学从"精密定点观测"向"大规模统计巡天"的范式转变。其宽视场能力将使系外行星普查数量从数千提升至数万级别，暗能量研究的统计样本将扩大一个数量级。与韦伯的深度观测形成互补，两者协同将构建从近邻宇宙到早期宇宙的完整观测链路。

P0 黑洞天体物理 首次观测

中国爱因斯坦探针卫星首次捕获中等质量黑洞撕裂白矮星事件

中国科学院国家天文台宣布，中国天关卫星（爱因斯坦探针，Einstein Probe）在2025年7月2日巡天观测中，探测到一个极其明亮且快速变化的X射线源EP250702a。该事件触发了全球多波段多望远镜联合观测，其亮度演化、辐射模式和光谱特征与任何已知宇宙爆炸显著不同。研究论文以封面文章发表于《Science Bulletin》。

研究团队提出令人信服的解释：这是一个中等质量黑洞（IMBH）通过潮汐撕裂事件（TDE）撕碎并吞噬一颗白矮星的过程——这是人类首次观测到此类极端事件。白矮星是恒星死亡后的超致密残骸，平均密度可达太阳的百万倍。理论上只有质量在数百至数十万倍太阳质量的中等质量黑洞，才具备足够强的潮汐力来撕裂如此致密的天体而非整体吞噬。

该事件X射线峰值光度达10^47-49 erg/s，在20天内从3×10^49 erg/s骤降至约10^44 erg/s，费米/GBM和Konus-Wind探测到延伸至数十MeV伽马射线的硬谱，表明存在相对论性喷流辐射。晚期出现的软X射线"余辉"成分可能源自吸积盘。

关键认知价值：中等质量黑洞是黑洞演化链中"缺失的环节"，连接恒星级黑洞与超大质量黑洞。此次首次直接观测到IMBH撕裂白矮星，不仅填补了黑洞质量分布的关键空白，还验证了白矮星潮汐撕裂事件的理论预测。这类事件是空间引力波探测器的理想源天体，为多信使天文学时代提供了电磁+引力波协同观测的新窗口。

P1 早期宇宙 理论突破

JWST"小红点"被确认为直接坍缩黑洞，挑战黑洞形成理论

詹姆斯·韦伯太空望远镜在早期宇宙中发现的大量"小红点"（Little Red Dots, LRDs）天体，长期困扰天文学界。这些致密、明亮且颜色极红的天体存在于大爆炸后约5亿至20亿年（红移z~4-7），数量远超同期类星体。哈佛大学领导的团队近期发表论文，通过辐射流体动力学（RHD）模拟，确认这些天体为正在吸积物质的"直接坍缩黑洞"（Direct-Collapse Black Holes, DCBHs）。

传统理论认为黑洞由大质量恒星坍缩形成，但这一过程需要数十亿年，无法解释大爆炸后数亿年内超大质量黑洞的存在。直接坍缩黑洞模型提出黑洞可由巨大原始气体云直接坍缩形成，绕过恒星演化阶段。中国华中科技大学吴庆文教授团队2026年提出补充机制，认为LRDs的红色源于黑洞吸积盘外围（温度约2000-4000°C）的自然辐射，而非星际尘埃红化效应。

该论文目前正在接受《Nature》期刊的发表评审。如果确认，将从根本上改变我们对早期宇宙黑洞形成和星系协同演化的理解。

关键认知价值：直接坍缩黑洞机制如获确认，将颠覆"黑洞必由恒星演化而来"的传统认知。这意味着在宇宙诞生后数亿年内，原始气体云可直接坍缩形成数万至数百万太阳质量的黑洞种子，为理解类星体如何在宇宙早期就达到数十亿太阳质量提供了可行的物理路径。这从根本上改变了超大质量黑洞形成的理论框架。

P1 空间科学 任务里程碑

中欧联合SMILE"微笑卫星"成功发射，首次实现地球磁层全景成像

北京时间2026年5月19日11时52分，中欧联合研制的太阳风-磁层相互作用全景成像卫星（SMILE，简称"微笑卫星"）在法属圭亚那库鲁航天中心由"织女星-C"火箭成功发射升空。卫星顺利进入预定轨道，太阳翼展开到位，发射任务圆满成功。这是中国科学院（CAS）与欧洲空间局（ESA）首次开展任务级全方位深度合作的空间科学探测任务。

SMILE卫星搭载了全球首台星载软X射线成像仪（SXI），通过探测太阳风离子与地球外层中性气体发生电荷交换产生的软X射线，将原本"不可见"的磁层边界转化为直观图像。卫星还搭载了紫外极光成像仪（UVI）、低能离子分析仪（LIA）和磁强计（MAG），构建了"成像+原位"协同观测体系，首次在全球尺度上成像追踪磁层演变。

中方首席科学家、CAS院士王赤表示，此前对磁层结构和相关过程的研究主要依赖单颗卫星的孤立观测和定点测量，难以建立完整的物理图像。SMILE将动态揭示太阳风-磁层耦合过程，在空间天气预报和磁层物理学基础认知等领域有望取得原创性突破。

关键认知价值：SMILE将首次让人类以"全景视角"看到地球磁层如何与太阳风相互作用——如同从"单点测温"升级到"卫星云图"。这对于理解空间天气、保护卫星和地面通信导航系统免受太阳风暴冲击具有直接应用价值，同时也为研究其他行星磁层环境提供了新的观测范式。

P1 月球探测 即将发射

中国嫦娥七号月球探测器进入发射最后准备阶段，目标月球南极

中国载人航天工程办公室宣布，嫦娥七号月球探测器已于2026年4月9日安全运抵海南文昌航天发射场，各组件通过空陆联运抵达。目前发射场设施设备状态良好，各项准备工作按计划有序推进，发射窗口定于2026年下半年。这是中国首次由载人航天工程办公室（而非国家航天局）发布月球探测任务信息，标志着载人月球探测与无人月球探测的深度整合。

嫦娥七号任务旨在突破月球表面高精度软着陆、足式移动、月面跳跃和永久阴影坑探测等关键技术。探测器由轨道器、着陆器、巡视器和一个飞跃器组成，采用"环绕+着陆+巡视+飞跃"综合探测模式，对月球南极环境与资源进行勘察。飞跃器将飞入月表坑洞中搜寻水冰，搭载6台国外科学载荷开展国际合作。

嫦娥七号之后，嫦娥八号计划于2028-2029年发射，将协助建设国际月球科研站（ILRS）的基本构型。中国在"十五五"期间（2026-2030）将加速推进载人登月、行星探测二期和卫星互联网等国家重大航天工程。

关键认知价值：月球南极永久阴影区可能蕴藏水冰资源，是未来月球基地建设和深空探测的战略要地。嫦娥七号的飞跃器设计是全球首创——可在月面多个坑洞间跳跃移动搜寻水冰，这超越了传统巡视器的单点探测模式。该任务的成果将直接决定未来月球科研站的选址和资源利用方案。

P1 深空探测 任务进展

NASA灵神星探测器成功飞越火星，传回震撼延时影像

NASA灵神星探测器（Psyche）于2026年5月15日成功完成火星引力辅助飞越，最近距离仅4500公里。探测器利用火星引力加速并调整轨道，朝着金属富集小行星灵神星方向前进，预计2029年抵达目标。飞越过程中探测器测试了多光谱成像仪、磁力计等科学仪器，并拍摄了数千张火星观测图像和延时视频。

此次飞越不仅是轨道调整的工程需要，更是对探测器科学仪器的实战演练。任务团队利用飞越机会校准成像技术，为2029年抵达小行星后的科学观测做准备。此前，该探测器还曾于2025年9月观测到星际彗星3I/ATLAS，历时8小时拍摄的多光谱图像帮助天文学家精确测定了该彗星的轨道参数。

灵神星位于火星与木星之间的小行星带，是一颗富含金属的M型小行星，直径约210公里。科学家认为它可能是早期行星形成时暴露的金属内核残余，研究它有助于理解行星分化和内核形成过程。

关键认知价值：灵神星可能是人类能直接观测的唯一天然"行星金属内核"样本。如果确认为裸露金属核，将首次直接验证行星分化理论——即行星在形成过程中重元素下沉形成金属核、轻元素上浮形成硅酸盐幔的模型。这对于理解地球等类地行星的内部结构和演化历史具有不可替代的科学价值。

P1 暗物质 理论挑战

银河系中心可能并非超大质量黑洞，而是暗物质团块

天文学家提出一项挑战性假说：银河系中心可能并不存在一个超大质量黑洞（人马座A*），而是一个巨大的暗物质团块，产生相同的引力效应。研究者认为这种不可见物质——可能是某种新型暗物质——以与黑洞相同的方式施加引力影响，但并非一个坍缩的时空奇点。

这一假说与近年来的多项观测存在张力。2026年1月，XRISM太空望远镜（NASA-ESA-JAXA联合项目）发现人马座A*在数百年前曾经历剧烈X射线爆发。密歇根州立大学团队通过研究银河系中心附近巨大气体云反射的X射线"光回声"，揭示了这个黑洞在近期曾有惊人爆发活动。这项研究发表于《天体物理学杂志通讯》。

上海天文台团队则利用脉冲星计时阵列（PTA）数据对暗物质进行约束，在Physical Review D发表的研究中，刘阔博士和陈思远博士团队对超轻标量暗物质和暗光子暗物质给出了新的质量上限。这些研究正在从不同角度逼近银河系中心真相。

关键认知价值：如果银河系中心是暗物质团块而非黑洞，将从根本上改变我们对宇宙结构的认知——意味着暗物质可以在极端引力条件下形成致密团块，其行为类似于黑洞但不产生事件视界和霍金辐射。这将同时为暗物质粒子性质提供强力约束。但目前主流证据仍支持黑洞模型，暗物质假说需要更多独立验证。

P2 月球科学 新发现

嫦娥六号样本揭示月球两面太阳风渗透差异

中国嫦娥六号从月球背面采集的样本揭示了一个令人惊讶的发现：太阳风粒子在月球背面土壤中的渗透深度远超正面。这是因为地球磁层在月球正面形成了一定程度的屏蔽，而背面在特定轨道位置更直接暴露于太阳风轰击之下。

这一发现对理解月球表面风化过程和挥发性物质分布具有重要意义。太阳风注入的氢、氦-3等元素是潜在的月球资源，两面渗透差异意味着月球背面可能富集更多太阳风植入的挥发性物质。这也解释了为什么月球正面和背面的土壤化学成分和物理性质存在系统性差异。

嫦娥六号于2024年5月发射，是人类首次从月球背面采样返回的任务，采集了1731克月壤样品。样品中发现的新矿物镁嫦娥石-(Y)和嫦娥石-(Ce)是中国科学家发现的第三和第四种月球新矿物。

关键认知价值：月球两面太阳风渗透差异的发现，为"月球背面更适合建设氦-3开采基地"提供了科学依据。同时揭示了地球磁层对近邻天体的实际保护范围和效果，对理解地月系统空间环境耦合具有基础性意义。这也提示未来月球基地选址需将太阳风暴露程度作为关键参数。

P2 行星探测 任务节点

ESA-JAXA BepiColombo水星探测器将于11月进入水星轨道

ESA与JAXA联合实施的BepiColombo水星探测任务将于2026年11月30日进入水星轨道。该任务于2018年10月发射，原计划2025年底入轨，因推进模块供电问题推迟至2026年11月。探测器需借助地球1次、金星2次和水星6次共9次引力辅助飞越才能减速入轨，以克服太阳强大引力。

BepiColombo由两个独立轨道器组成：ESA主导的水星行星轨道器（MPO，携带11台科学仪器，进入400km×1500km极轨道）负责探测水星表面和内部结构；JAXA主导的水星磁层轨道器（MMO/Mio，携带5台科学仪器，进入400km×12000km极轨道）负责探测水星磁场与太阳风相互作用。这是人类第三个造访水星的探测器。

MPO上的水星轨道无线电科学实验（MORE）还将测试爱因斯坦广义相对论，利用水星近日点的精确测量来确定爱丁顿参数。激光高度计BELA将绘制全球地形图，热红外光谱仪MERTIS将进行表面矿物学成像。

关键认知价值：水星是太阳系中最靠近太阳的行星，其极端环境（表面温差达600°C）使其成为研究行星形成和演化的独特实验室。BepiColombo的双轨道器协同观测将首次同时获取水星表面成分、内部结构和磁场环境的完整图景。广义相对论测试将在最强引力场条件下对爱因斯坦理论进行新的精度检验。
来源：ESA / JAXA / BepiColombo Mission · 2026（入轨预定2026.11.30）

P2 行星科学 古生物交叉

科学家确认灭绝恐龙的小行星属于罕见CO型碳质球粒陨石

科学家确认6600万年前撞击地球、导致非鸟类恐龙大规模灭绝的小行星，属于一种极其罕见的CO型碳质球粒陨石（CO chondrite），来自太阳系遥远的外侧区域。这一结论基于对该撞击事件的化学指纹分析和全球KT界线地层中铱异常的精细研究。

CO型碳质球粒陨石的化学成分异常特殊，其不含普通球粒陨石中的大量金属铁，但富含难熔有机物和水合矿物。这种化学特征意味着撞击产生的全球降温效应可能比此前预估的更严重——富含挥发性物质的陨石在撞击时会释放更多冷却气体和尘埃，导致更持久的"撞击冬季"。

研究还发现约8亿年前一次灾难性小行星解体事件可能对内太阳系产生了大规模撞击波及。这些发现为理解太阳系小天体动力学和行星防御策略提供了新的时间尺度参照。

关键认知价值：确定灭绝事件陨石的类型不仅具有古生物学意义，更直接影响行星防御策略。CO型碳质球粒陨石富含挥发性物质，撞击时会产生更多冷却尘埃，这意味着即使是中等规模的小行星撞击也可能引发比预期更严重的气候灾变。这对近地天体威胁评估和防御优先级排序具有直接指导意义。
来源：ScienceDaily / Nature Communications · 2026.07.19 / 2026.07.18

P2 黑洞天体物理 新发现

上海天文台提出吸积盘与喷流形成新理论，揭示黑洞"风暴之眼"

中国科学院上海天文台研究人员提出关于吸积盘和喷流形成的新理论，为理解黑洞如何将落入物质转化为高速喷流提供了新视角。同时，该台与国际合作者利用2018年事件视界望远镜（EHT）和全球毫米波VLBI阵列观测数据，对M87黑洞进行了首次空间分辨双频光谱研究，揭示了视界尺度辐射性质的新细节。

此外，上海天文台还在银河系"运动画面"研究中揭示了暗物质晕的形状。通过对扭曲银河系盘面的运动学分析，研究人员获得了暗物质晕三维形状的直接约束，为暗物质粒子性质提供了间接限制。

国际DESI项目也成功完成了五年巡天计划，通过对数千万星系和类星体的光谱观测，对暗能量状态方程参数给出了新的约束。这些成果共同推动着对宇宙暗成分（暗物质+暗能量）本质的逼近。

关键认知价值：吸积盘-喷流耦合是黑洞物理中最未理解的过程之一。新理论如果成立，将为统一解释从恒星级到超大质量黑洞的喷流形成提供理论框架。银河系暗物质晕形状的测定直接约束了暗物质粒子模型——不同暗物质候选者（WIMPs、轴子、模糊暗物质）预测不同的晕形状。
来源：中国科学院上海天文台 / DESI International Project · 2026.04-07
