P0 黑洞物理 中国科学院
M87黑洞首张谱指数图像发布：从“看见”黑洞走向“读懂”黑洞

中国科学院上海天文台路如森研究员团队与国际合作者，利用2018年事件视界望远镜（EHT）和全球毫米波VLBI阵列（GMVA）的观测数据，对M87黑洞开展双频联合谱指数成像研究。通过对1.3毫米和3.5毫米两个波段获得的黑洞视界尺度图像进行联合分析，首次获得了黑洞事件视界尺度的空间分辨谱指数分布。论文7月20日发表于《天体物理学杂志通讯》。

研究发现，黑洞周围辐射性质随与黑洞中心的距离变化而发生显著改变：靠近中心区域谱指数为正，表明该区域辐射仍受同步辐射自吸收影响；随着距离增加，谱指数逐渐下降并由正转负，显示辐射过渡到光学较薄状态。这一转变发生在距黑洞中心约30微角秒的位置，与3.5毫米波段观测到的环状结构尺度一致，证明黑洞图像中的环状结构不仅反映辐射形态，还与视界附近等离子体的辐射状态密切相关。

路如森研究员表示，谱指数反映了黑洞周围物质在不同观测频率下的辐射特性，是理解黑洞附近辐射机制的重要线索。此前单一频率图像只能反映空间结构，只有结合不同频率观测结果，才能揭示辐射背后的物理性质，推动黑洞研究从“看见黑洞”迈向“读懂黑洞”。

关键认知价值： 这是迄今为止人类获得的首张空间分辨的黑洞事件视界尺度谱指数图像，相当于为黑洞开展了一次高精度的“空间光谱体检”。该成果将黑洞研究从静态结构成像推进到动态物理诊断，为验证极端引力场中的物质行为理论提供了关键观测约束。
信源：中国科学院上海天文台 / 《天体物理学杂志通讯》(ApJ Letters) 2026.07.20 / 新华社 / China Daily

P0 星际化学 NASA 观测突破
NASA SPHEREx首绘银河系星际冰分布图：揭示地球之水可能起源于星际空间

NASA的SPHEREx空间望远镜项目团队在《天体物理学杂志》发表成果：在天鹅座X等恒星形成区，探测到延展超600光年的广阔冰区。这是人类首次绘制出银河系规模空前的星际冰分布图，为回答“行星上的水最初从哪里来”提供了关键线索。

SPHEREx能同时记录102种红外“颜色”，覆盖了水冰(3.0微米)、二氧化碳冰(4.27微米)、一氧化碳冰(4.67微米)等关键吸收波长。研究团队发现，连星际空间弥漫的背景辐射也携带着冰的信息，使得以前所未有的广度绘制冰分布图成为可能。在天鹅座X区域，哪里尘埃最密集，哪里冰就最多，最高浓度出现在分子云最致密的核心区。

在极度寒冷的分子云中（温度约零下260摄氏度），气体分子凝结在尘埃颗粒表面形成冰膜，而最致密的云核能遮挡新生恒星的紫外线，充当冰的“保护伞”。水可能已以冰的形式存在于星际空间，随着恒星和行星的诞生被带入新生的行星系统。

关键认知价值： 该发现为“地球之水从何而来”这一经典问题提供了观测级线索——水可能并非地球原生产物，而是在恒星形成之前已以冰的形式广泛存在于星际空间，随后被“缓冲”入行星系统。这改写了行星水起源的默认假设。
信源：NASA SPHEREx / 《天体物理学杂志》(The Astrophysical Journal) / 人民日报科技大观

P0 系外行星 欧南台 首次探测
《自然》发文：人类有望首次探测到系外卫星候选天体，径向速度法开辟新路径

英国《自然》杂志7月22日发表一项重大研究：国际团队借助欧洲南方天文台设在智利的畦大望远镜(VLT)，观测并分析了CD-35 2722恒星系统，发现了一个围绕褒坨星运行的天体存在证据。这是人类数十年搜寻系外卫星道路上里程碑式进展，但尚未最终定论。

该系统为三层等级结构：主恒星质量约为太阳一半，褒坨星CD-35 2722 B环绕主恒星运行，新发现的天体又围绕褒坨星运行。研究团队在2023年10月至2026年2月期间使用径向速度分析法进行监测，发现该候选卫星最小质释约为0.9倍木星质量，轨道周期约170天。这也是径向速度法首次用于搜寻卫星级天体。

尽管已发现超过6000颗系外行星，但过去所有疑似系外卫星均因信号噪声、数据偏差被学界推翻，没有一颗获得公认确认。若最终确认，将完整印证恒星系统逐级孕育次级天体的普遍规律，并验证径向速度法搜寻微小卫星的可行性。

关键认知价值： 若最终确认，这将证明卫星并非太阳系独有，为今后批量寻找宜居带系外卫星、探寻地外生命栖息地开辟全新路径。但需注意，远遥天体观测极易受恒星活动、仪器噪声干扰产生虚假周期信号，仍需后续多国望远镜长期复测。
信源：《自然》(Nature) 2026.07.22 / 欧洲南方天文台(ESO VLT) / 新华社

P0 太阳物理 NASA
NASA研究称太阳风暴对地球影响可能无上限：《自然》发文颠覆传统认知

NASA牵头的一项研究7月15日发表于《自然》杂志，提出太阳风暴对地球技术基础设施的影响可能没有上限。数十年来，科学家一直认为地球对太阳风暴的响应存在一个天花板，但该论文认为这个上限是一种错觉。

如果该结论成立，意味着太阳风暴可能对人类技术产生远比预期更为严重的影响，包括电力网、通信卫星、GPS导航等关键基础设施。这项研究直接关乃地球空间天气预报体系的基础假设是否需要重新评估。

关键认知价值： 该研究颠覆了“太阳风暴对地球影响有上限”的传统认知，如果成立，将迫使空间天气预报体系修改其极端事件评估模型，对现代社会的基础设施露脆性评估产生深远影响。
信源：NASA / 《自然》(Nature) 2026.07.15 / NASA Goddard科学新闻

P1 黑洞 NASA Swift
NASA Swift首次发现星系外围“流浪”超大质量黑洞撕裂恒星

NASA的Neil Gehrels Swift天文台捕获到一个“孤儿”黑洞在遥远星系的外围亮起来，正在吞噬一颗恒星。这类现象本身就很罕见，而且以前从未在星系核心之外如此远的位置观测到。

这一发现表明，超大质量黑洞不仅仅存在于星系中心，还可能在星系外围“流浪”，它们通过撕裂经过的恒星来“进食”。这对理解黑洞如何在星系中心形成和增长提出了新问题。

关键认知价值： 首次在星系外围发现超大质量黑洞撕裂恒星事件，挑战了“超大质量黑洞只存在于星系中心”的传统认知，为黑洞迁移与星系演化的关系提供了新观测约束。
信源：NASA Neil Gehrels Swift Observatory 2026.07.27 / NASA Goddard科学新闻

P1 月球科学 嫦娥六号
嫦娥六号揭示月球正背面太阳风差异：地球磁层球充当“调速器”

中国嫦娥六号任务返回的月背面样品揭示了一个惊人的差异：月球背面接收到的太阳风粒子几乎以全速撞击，而月球正面（朝地球面）被同样的太阳风击中时速度已被减缓近一半。该发现发表于《自然-地球科学》。

中国研究人员对来自南极-艾特肯盆地的样品进行了五种稀有气体分析，发现地球磁层球充当了一个天然的“调速器”——在太阳风到达月球正面之前，偏转并减速了太阳风。这一效应永久地锁定在月壤的稀有气体记录中。

月球缺乏全球磁场和保护性大气，其表面充分暴露于太阳风之下，使其月壤充当了一个长期“时间胶囊”，保存了数十亿年来太阳、月球和地球之间相互作用的档案。

关键认知价值： 首次通过月背面样品证明地球磁层球对月球正面太阳风的减速效应，将日地月三体系统的物理联动从定性描述推进到定量化分析，为理解太阳风在太阳系内的输运提供了新约束。
信源：中国嫦娥六号任务 / 《自然-地球科学》(Nature Geoscience) / China Daily 2026.07.21

P1 系外行星 NASA Webb
韦伯望远镜在绘架座β星系发现隐藏巨行星，开层光谱法探测行星新路径

天文学家使用NASA的詹姆斯·韦伯空间望远镜(JWST)，在备受瞩目的年轻恒星系统中取得重大突破：通过检测行星的大气化学特征，成功揭开了隐藏在明亮尘埃盘中的第三颗巨行星——“绘架座β d”的神秘面纱。

绘架座β系统距地球约63光年，年龄仅约2300万年，是研究恒星与行星系统形成及演化的重要“天然实验室”。该发现使绘架座β成为已知第二个拥有至少三颗被成像/探测到行星的恒星系统。研究团队意外发现了一氧化碳分子吸收线构成的“条形码”犹如气态巨行星大气的代表性特征，并通过MIRI检测到甲烷和水蒸气进一步证实。

该发现开创了通过大气光谱特征“扫描”并发现复杂尘埃环境中隐匿行星的新方法，研究成果发表于《天体物理学杂志快报》。

关键认知价值： 该发现开创了在尘埃和碎片盘复杂环境下探测隐匿行星的新方法，为未来在其他年轻恒星系统中搜寻类似木星的气态巨行星提供了可复制的观测路径。
信源：NASA James Webb Space Telescope (JWST) 2026.07.15 / 《天体物理学杂志快报》(ApJ Letters)

P1 星系演化 NASA Hubble
哈勃发现仙女座星系恒星形成正在衰减：已持续5亿年下降

NASA的哈勃空间望远镜发现，仙女座星系（M31）的恒星形成已经历了一次5亿年的衰减。仙女座星系是距离银河系最近的大型螺旋星系，距地球约250万光年。

这一发现表明，即使是银河系最亲近的大型邻居，其恒星形成也在经历漫长的衰退期。这为理解螺旋星系的演化命运提供了重要的局部观测约束。

关键认知价值： 仙女座星系作为银河系的“未来镜像”，其恒星形成的衰减过程可能预示着银河系未来的演化方向，为星系生命周期理论提供了珍贵的实际观测数据。
信源：NASA Hubble Space Telescope 2026.07.27 / NASA Goddard科学新闻

P2 深空探测 NASA Psyche
NASA Psyche探测器成功完成火星飞越，借助引力助推奔赴金属小行星

NASA的Psyche宇宙飞船成功完成了火星飞越，利用火星的引力加速向其2029年与一颗富含金属的小行星交会的目标进发。飞船在飞越期间测试了其照相机、磁强仪和其他仪器。

Psyche任务旨在探索一颗被认为是行星核心轮露表面的金属小行星(16 Psyche)，它可能提供有关行星内部构造和太阳系形成初期的独特见解。这颗小行星由大量铁和镍金属组成，与地球核心的成分相似。

关键认知价值： Psyche任务是人类首次近距探测一颖可能是“行星核心轮露”的天体，其结果将直接检验有关行星内部分化和核心构造的理论模型。
信源：NASA / ScienceDaily 2026.07.28

P2 载人航天 中国载人航天
神舟二十三号乘组在轨满60天，空间站实验密集推进

神舟二十三号乘组航天员朱杨柱、张志远、黎家盈在中国空间站工作生活已满60天。乘组计划新开展100余项空间科学与应用项目，近期利用太空拉曼光谱仪进行菌群与营养代谢相关实验研究。

中国载人航天工程办公室近日开放了空间站2026年度科学研究与应用类项目征集，主要聚焦空间生命科学与生物技术、空间微重力物理、空间新技术与应用三大领域，具体涵盖了23个指南方向。

关键认知价值： 神舟二十三号乘组在轨密集开展多领域科学实验，包括肠道菌群与营养代谢、精细动作控制等，这些实验为人类长期太空飞行的生物医学保障提供了关键数据。
信源：中国载人航天工程办公室 / 新华社 / 岁台网 2026.07.27

P2 空间安全 中国
中国开建商业空间碎片监测星座，增强轨道环境安全

中国已开始建设商业空间碎片监测星座，用于监测和跟踪在轨道上运行的空间碎片，提高轨道环境的安全性。这是中国在空间态势感知能力方面的重要进展。

随着太空发射活动日益频繁，轨道碎片对活跃卫星和载人航天任务构成严重威胁，建立专门的监测星座是必要的防护措施。该系统将能够提供空间物体的实时监测和危险预警。

关键认知价值： 随着中国空间活动频率加快，空间碎片管理已成为必要的基础设施。该项目标志着中国正在从“被动观测”转向“主动管理”轨道环境安全。
信源：新华网 / People's Daily Online 2026.07.27

P3 月球探测 NASA Artemis
NASA选6亿美元投4项新月球任务，推进永久月球基地建设

NASA选6亿美元授5.9亿美元授予了四项商业月球着陆任务，计划于2028年底执行。每项任务将携带相同的三种科学仪器，用于改进月球导航、研究着陆时扬起的危险粘土等。NASA正努力在2030年前建立月球基地。

同时，NASA宣布Artemis III（2027年）将进行一次异常雄心勃勃的轨道演习：Orion宇航员将分别与SpaceX和Blue Origin的月球着陆器交会对接，以测试未来载人着陆的安全流程。

关键认知价值： 这是NASA建立永久月球基地计划的关键步骤，多家商业合作伙伴并行开发着陆器的模式，标志着月球探测正从“单次访问”转向“持续存在”。
信源：NASA / ScienceDaily 2026.07.14 / 2026.07.23
