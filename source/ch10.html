P0 节气养生 健脾祛湿

中伏湿热困脾：辨清寒湿与湿热，对症祛湿不伤阳

大暑至立秋期间，长夏主湿，太阴湿土当令，暑湿交蒸达全年顶峰。人体阳气浮于体表，脾胃阳气相对虚弱，外界湿邪极易侵入中焦。门诊数据表明，近期脾胃不适患者显著增多，多见食欲差、腹胀乏力、身体沉重、大便黏腻等症状。中医强调祛湿无通用方，须先辨寒热再调养，盲目喝薏米水、凉茶反而越祛越虚。

寒湿困脾型（畏寒怕冷、手脚冰凉、大便溏稀、舌苔白厚）：忌凉茶寒凉，宜温阳健脾，日常用生姜、红枣、炒薏米、白扁豆温和养护。

湿热蕴脾型（口苦口黏、面部出油、大便黏马桶、舌苔黄腻）：宜清热化湿，适量食用冬瓜、赤小豆、荷叶、茯苓，坚持清淡饮食。

脾虚湿盛型（饭后腹胀、四肢乏力、晨起疲惫、大便时溏时黏）：重在健脾固本，多食山药、芡实、陈皮，脾胃强健则湿气自除。

居家建议：三餐规律七分饱，忌空腹吃生冷甜腻；雨天做好防潮，晴天开窗通风除湿；空调不直吹胃脘腹部；少久坐多活动，动则生阳助脾胃运化。遵循"清暑不寒凉，祛湿不伤脾"原则。

P0 运动科学 高温安全

高温运动安全：心率上限公式与"说话测试法"双保险

2026年8月全国多地发布高温橙色预警，三伏进入中伏核心期。运动医学研究表明，气温每升高1℃，运动中心血管事件风险显著上升。北京中医药大学东方医院治未病科主任刘洋指出，三伏天运动核心准则是"微汗而不淋漓"。运动科学提出三重自测法：说话测试、体感自查、心率监测，交叉判定安全强度。

说话测试法：运动时能连贯说出短句，说明强度适中；气喘吁吁无法说完整句，应立即降速。

心率监测法：目标心率 = (220 - 年龄) × 60%~70%。以40岁为例，运动心率应保持108~126次/分钟；50岁对应102~119次/分钟。超过上限必须降速。

时间死线：10:00-16:00禁止户外高强度运动。最佳窗口：清晨6:00-8:00、傍晚18:30后。气温超29℃减量，超32℃转入室内。

热身不可省：5-10分钟动态热身（慢跑+动态拉伸+专项激活），提前启动体温调节机制，降低运动损伤风险。

来源：北京中医药大学东方医院 / 中国体育科学研究所 / 多地体育部门高温运动安全指引

P0 起居调摄 防寒护阳

"伏阴在内"警示：三伏最忌贪凉，护住三个关键部位

中医认为三伏天"伏阴在内"——看似天气燥热，实则是寒气潜伏脾胃深处。北京儿童医院顺义妇儿医院专家指出，长期吃冰镇西瓜、冷饮、冰奶茶会直接损伤脾阳、锁住寒湿，秋冬易引发胃痛、腹泻、手脚冰凉、体虚乏力。空调冷风趁毛孔大开时偷袭人体，可致血管收缩、肌肉紧张，诱发面瘫、关节痹痛。

护三部位：即使天气再热，也要盖好腹部（神阙穴）、后颈（大椎穴）、膝盖。空调温度不低于26℃，老人慢病群体建议27-28℃。

忌汗后直吹：运动后或出汗后腠理大开，进入空调房或直吹电扇最易风寒入侵。应先擦干汗水、换上干爽衣物再纳凉。

每日通风：开窗通风半小时排湿气，避免室内湿浊郁积。空调风口切勿直吹颈肩、腰腹、膝盖。

入口温度：所有入口食物以温热、常温为主。冰水瞬间收缩胃肠道血管、降低消化酶活性，食物堆积化为痰湿。

P1 饮食调理 药食同源

三伏饮食三大误区揭秘：以热制热比冷饮更解暑

良乡医院中医科主任谢利利指出，三伏天身体"阳浮于外，阴伏于内"，脾胃消化能力大幅下降。很多人陷入三大致胖饮食误区：无冰不欢靠冷饮降温、水果代餐当减脂晚餐、顿顿吃素追求极致清淡。中医讲究"省苦增辛"，苦瓜、苦丁等苦寒食材需搭配生姜、大蒜等温性辛味食材中和寒气。

以热制热原理：喝热水、热姜枣茶可扩张毛细血管，顺畅排汗，汗液蒸发带走深层热量，降温更持久，同时护住脾胃阳气。

三伏一日轻身食谱：

早餐——温热升阳：必吃热鸡蛋，搭配小米粥、醋泡姜
午餐——健脾祛湿：冬瓜扁豆排骨汤 + 山药炒时蔬 + 杂粮饭
晚餐——清淡七分饱：莲子百合小米粥 + 清蒸鱼 + 凉拌木耳

代茶饮推荐：陈皮茯苓水（陈皮3g、茯苓5g）健脾祛湿；山楂荷叶姜枣茶消食祛湿控重；西洋参石斛麦冬饮补气生津止汗。

P1 营养学 免疫研究

协和医院最新研究：规律补充复合维生素矿物质降低感冒风险42.8%

2025年7月，中国医学科学院北京协和医院临床营养科王方、于康在亚太临床营养学会官方期刊《亚太临床营养学杂志》发表大规模真实世界研究：规律补充复合维生素和矿物质制剂，能显著降低急性上呼吸道感染发生率42.8%，并有效减轻发热、流涕、鼻塞、喉咙痛、咳嗽、打喷嚏、肌肉疼痛、疲劳8大感冒症状。

核心机制：复合维生素矿物质通过协同作用增强黏膜屏障、调控免疫细胞分化（T细胞）及抗炎反应。维生素D促进抗菌肽分泌，维生素C保护中性粒细胞、促进铁吸收，锌调节Th细胞平衡。

关键发现：复合制剂生物利用度优于单一补充剂，需持续规律补充3个月以上方可见效。VC、VD、锌、硒四种营养素协同免疫效果远优于单一补充。

夏季特别提示：高温出汗加速水溶性维生素流失，日常饮食不足者可考虑补充。VC推荐每日100mg，单次200mg吸收率达100%，超量反而吸收率骤降。

适用人群：饮食不均衡人群、易感冒者、免疫力低下者。健康人群优先从食物获取：柑橘类水果补VC，粗粮补B族，深海鱼蛋黄补VD。

来源：北京协和医院临床营养科 / 亚太临床营养学会期刊(APJCN) / 《Nutrients》《AJCN》相关研究

"情绪中暑"防治：静心戒怒，午时养心安神

《黄帝内经》云："夏三月，使志无怒，使华英成秀。"暑气通于心，高温闷热最易扰动心神，引发烦躁、易怒、失眠——即"情绪中暑"。心为君主之官，心乱则百病生，心静则万病息。三伏天心火偏亢，心烦、燥热、多梦、易醒为高发症状，养生重在"静"。

P1 睡眠科学 昼夜节律

《2026中国睡眠白皮书》：超6成人睡不好，规律作息比睡够8小时更重要

中国睡眠研究会联合发布的《2026中国睡眠健康管理白皮书》显示，约60%的消费者存在睡眠困扰。30岁前后褪黑素水平持续降低，60-70岁后明显减少。密苏里大学2026年7月发表于《行为医学杂志》的研究发现，保持规律日常生活习惯（固定起床、吃饭、互动、睡觉时间）可减轻身体疼痛并缓解抑郁症状，效果独立于睡眠质量。

四维改善方案：

1. 重塑昼夜节律：固定起床时间，起床后尽快接触自然光校准生物钟；临睡前1小时不看屏幕减少蓝光。

2. 优化睡眠环境：保持卧室黑暗、安静、凉爽（24-26℃），湿度50%-60%；睡前2小时调暗房间光线；睡前泡脚保持双脚温暖。

3. 适度锻炼：傍晚快走30分钟促进内啡肽分泌和褪黑素产生；睡前2小时避免高强度训练。

4. 饮食调整：晚餐清淡，下午3点后不摄入咖啡因，睡前避免饮酒（酒精抑制深睡眠）。

关键认知：8小时非金标准，睡醒后状态才是核心指标。白天精力不足、情绪波动才是身体发出的需要高质量休息的信号。

来源：中国睡眠研究会 / 《2026中国睡眠健康管理白皮书》 / 密苏里大学《行为医学杂志》研究

P2 慢病管理 心肾保护

高温加重心肾负担：心脑血管及糖尿病患者夏季防护要点

研究显示，温度每升高1℃，心血管疾病死亡率增加2.1%，发病率增加0.5%。当最高气温从17℃升至32℃时，急性肾损伤发生可能性增加约62.3%。夏季高温导致体表血管扩张、血液流向体表散热，心率加快，心脏供血供氧相对减少；大量出汗致血容量不足、血液浓缩黏稠，血栓风险升高；电解质紊乱扰乱心脏节律。

心脑血管人群：切忌晨起冷水洗脸（血管骤缩致血压飙升）；空调26℃不低于24℃；正午10-16点减少外出；随身携带急救药物。日常按揉内关穴（腕横纹上三指宽），每日早晚各3分钟，宁心安神。茶饮推荐：麦冬6g、五味子3g、党参5g煮水，生脉饮基础配伍，补气敛汗。

糖尿病患者：西瓜甜瓜葡萄不可过量、不冰镇；冰寒损伤脾胃运化加剧血糖波动；高温加速胰岛素降解，需加强血糖监测；注意防脱水，补水以温开水为主。

通用原则：咸菜腌肉卤味少吃（咸味入血加重血管负担）；多吃冬瓜、木耳、芹菜等清淡利水食材；主动足量补水，每日不少于1500ml，小口多次饮用温水。

来源：心血管及肾脏病学高温风险研究 / 多家中医院慢病夏季养护指南

P2 电解质管理 补水策略

科学补水防低钠血症：运动超1小时须补电解质饮料

中国营养学会秘书长韩军花指出，高温运动中单纯喝白开水而未及时补充电解质，容易导致低钠血症，造成肌肉抽筋或其他不适。大量出汗带走钠、钾、钙、镁等维持心肌正常电活动的核心电解质，单纯补水会进一步稀释血液电解质，导致心肌细胞电信号不稳定，诱发心律失常。

分层补给策略：

运动前2小时：分次饮用500ml含电解质水

运动中：每15分钟补充150-200ml（9-12℃水温最佳）；超过1小时需补充含钠饮品（钠含量40-80mg/100ml）

运动后：体重每下降1kg补水1.5L

日常电解质食物来源：香蕉（每100g约含256mg钾）、咸味饼干补钠、粗粮补B族维生素、深海鱼蛋黄补维生素D。

糖电解质饮料标准：糖分含量3%-8%，钠钾钙镁电解质须达一定浓度才能实现真正补给效果。日常非运动人群优先从食物获取电解质，高温作业者可在医师指导下选择运动饮料。

P2 经络调理 居家实操

三伏经络穴位日常调理：三大要穴按摩与八段锦微汗法

中医认为三伏天经络气血通达，是疏通经络瘀堵的黄金窗口期。居家可通过穴位按揉与传统导引术，顺势排寒祛湿、固本培元。广西卫健委联合中医药局发布的三伏健康指引明确推荐：选择清晨或傍晚练习八段锦、太极拳等传统导引术，以微微出汗为宜。

三大日常要穴：

内关穴（腕横纹上2寸）：宁心安神、疏通冠脉气血，每日早晚各按3分钟，缓解夏季心烦胸闷。

足三里（外膝眼下3寸）：健脾和胃、补中益气，每日按揉5分钟，增强脾胃运化，改善食欲不振、腹胀。

太冲穴（足背第1-2跖骨间）：疏肝理气、清肝降火，每日按揉5分钟，缓解情绪烦躁、肝郁气滞。

八段锦微汗法：每日15-20分钟，室内阳台或公园均可。核心标准：周身微微发热、少量出汗即止，切忌大汗淋漓耗气伤津。重点动作"调理脾胃须单举""双手托天理三焦"特别适合长夏健脾祛湿。

艾灸辅助：中脘穴（脐上4寸）艾灸健脾胃；关元穴（脐下3寸）艾灸培补元气。每穴10-15分钟，隔日一次。

P2 立秋前瞻 秋包伏

"秋包伏"防暑不松懈：立秋后16天伏天余威与过渡期养生策略

2026年立秋交节时间为8月7日19:42（农历六月廿五），属"闭眼秋""晚立秋"，同时是典型"秋包伏"——立秋后仍有16天伏天（末伏8.14-8.23）。民间"秋包伏，热得哭"表明立秋后高温不会快速退场，防暑须持续到8月底。立秋后气候模式从"持续高温高湿桑拿天"逐渐转为"白天燥热、早晚清凉"，昼夜温差持续扩大，空气湿度逐渐下降。

过渡期三大转变：

1. 湿退燥生：立秋后阳明燥金当令，湿热渐退、燥邪初生，易出现口干咽燥、皮肤干痒、肺燥咳嗽。饮食从"祛湿为主"逐步增加润燥食材——银耳、百合、莲藕、秋梨。

2. 阳气收敛：天地阳气由盛转衰，人体阳气开始收敛内收。起居从"夜卧早起"逐步过渡到"早卧早起"，避免熬夜耗阴。

3. 温差防护：早晚凉意渐显，适时增减衣物，护住腹部和后颈。空调使用时间逐步缩短，夜间可开窗通风代替空调。

饮食过渡建议：适当减少寒凉饮食（绿豆汤、苦瓜频率降低），增加山药、莲藕、红枣等健脾食材，为入秋做准备。但末伏余热未消，不可骤然进补温热食物，仍以清补为主。

关键提醒："秋老虎"午后紫外线强度不减，防晒防暑不能因立秋就放松警惕。末伏昼夜温差拉大，早晚可感秋风凉意，注意适时增减衣物。
