01
大暑清补兼施：健脾化湿粥方与三豆饮升级版
P0节气养生饮食调理

大暑时节暑热与湿气交织，人体脾胃功能易受湿邪困扰。《黄帝内经·素问》指出"湿困脾土，宜清利淡渗"。2026年丙午年四之气，主气客气均为太阴湿土，湿气偏重尤甚，健脾祛湿成为贯穿大暑养生的核心。

医理讲解：暑性升散，易耗气伤津，使人出汗过多、疲倦乏力；湿性黏滞，易困脾阳，导致腹胀、大便不爽、头重如裹。脾主运化水湿，脾虚则湿聚，故清暑必先健脾，祛湿兼顾护阳。

具体建议（饮食）：
  • 三豆饮升级版：绿豆、赤小豆、黑豆各20克，加陈皮数片、冰糖少许煮汤。绿豆清暑热，赤小豆利湿，黑豆补肾清热，陈皮理气化湿。全家饮用，平和不偏。
  • 芳香化湿粥：白扁豆、薏苡仁、茯苓各15克，与粳米同煮，晨起食用。改善头面油光、舌苔厚腻、身体困重。
  • 酸甘化阴：暑热耗津时，常饮乌梅白糖汤或柠檬蜂蜜水，生津止渴，收敛浮火。
适用人群：食欲不振、身体困重、舌苔厚腻者，大众日常保健。脾胃虚寒者绿豆汤可加生姜两片中和寒性，不宜冰镇。
来源：《黄帝内经》素问·四气调神大论 / 山东中医药大学附属医院 / 广东省中医院
02
大暑护阳核心："清而不过寒，补而不过腻"饮食准则
P0脏腑养护饮食禁忌

山东中医药大学附属医院消化内科主任医师王伟提出大暑饮食核心准则："清而不过寒，补而不过腻"。夏季人体阳气浮于体表，内脏相对虚寒，大量食用冰镇饮料、生冷瓜果会直伤脾肾阳气。

三大饮食误区须避开：
  • 误区一：过量冷饮冰食——直接损伤脾胃阳气，导致腹胀、腹泻、四肢冰凉。
  • 误区二：烧烤重油重辣——加重脾胃负担，助湿生热，越吃越困。
  • 误区三：长期大量喝凉茶——体质虚寒者损伤正气，越喝湿气越重。
具体建议：清淡饮食的核心是易消化、低油腻，而非舍弃营养。高温下蛋白质消耗激增，需合理摄入鱼虾、禽肉、蛋类、豆制品等优质蛋白。补水遵循"少量多次、主动补充"，日常饮温开水，切勿口渴后一次猛灌。

"冬吃萝卜夏吃姜"：早晨含两片醋泡生姜，或用紫苏叶泡水，温暖中焦，驱散内留之寒湿。烹饪适量添加生姜、陈皮、砂仁等辛温食材，温补脾胃、提振食欲。
来源：山东省卫生健康委"鲁医健康说" / 山东中医药大学附属医院
03
高温天气心血管保护：气温每升1℃，心血管疾病发病率增约2%
P0常见病预防心血管

研究表明，气温每升高1℃，心血管疾病的发病率便会增加约2%。高温使体表血管扩张散热、心率加快、心肌耗氧量飙升；大量出汗导致脱水、血液黏稠、电解质流失。中老年及心血管基础病人群尤需警惕。

三重隐形攻击：
  • 血压波动：高温使血压下降，突然进入低温空调房则血压骤升，血管弹性下降的中老年人易诱发心梗、脑梗。
  • 心率加快：心脏代偿性加速跳动，心肌耗氧量显著增加，易诱发心律失常。
  • 血容量变化：大量出汗脱水致血液黏稠，钾镁流失，血栓风险飙升。
护心5条黄金准则：
  • 每日饮水1500-2000ml，少量多次温水慢饮，不喝冰水、浓茶、高糖饮料
  • 空调温度不低于26℃，不对着风口直吹；从户外进空调房先在阴凉处过渡5-10分钟
  • 清淡饮食七分饱，多吃香蕉、菠菜等富钾食物
  • 运动选清晨或傍晚，以散步、太极拳为主，微微出汗为宜
  • 坚持规律服药，绝不擅自停药减量
禁忌：大汗状态下不冲冷水澡、不暴食冷饮；高温时段（11:00-16:00）不外出。
来源：商丘市立医院心血管内科 / 《BMJ》高温与心梗风险研究 / 美国心脏协会2026年立场声明

夏季电解质科学补充：钠钾镁钙随汗流失的精准管理
P0营养学运动科学

电解质（钠、钾、钙、镁、氯等）参与肌肉收缩、心脏跳动、神经传导等核心生理过程。大量出汗时身体流失的不仅是水分，还有随汗液带走的电解质。若只补白水忽视电解质，可能出现乏力、疲倦甚至影响心血管功能。

科学补液原则：
  • 日常微汗：主动摄入含钠、钾元素的食物，如香蕉（补钾）、菠菜（补镁）、坚果（补镁）
  • 运动大汗：汗液成滴出现即为脱水和脱电解质状态，应选含钠钾镁的运动饮料或淡盐水
  • 每日基础：饮水不低于2000ml，出汗较多可增至3000ml，首选温白开水
食物补充方案：
  • 钾：香蕉、菠菜、红薯、豆类（每100g长豆角含钾207mg）
  • 镁：坚果、全谷物、深绿色蔬菜
  • 钠：出汗多时可饮淡盐水，高血压患者夏季可适度微调盐分，无需过度严苛限盐
  • 维生素C：鲜枣、猕猴桃、西兰花，每日建议100mg，增强皮肤防晒能力
适用人群：户外工作者、运动健身者、大量出汗者、老年人群。高血压患者需遵医嘱控制钠摄入。
来源：中国农业大学食品科学与营养工程学院 / 北京体育大学运动营养与健康实验室 / 《Nutrients》期刊

大暑起居调摄：夜卧早起、午间小憩、空调有度
P1日常起居作息

《黄帝内经》建议夏季"夜卧早起，无厌于日"。大暑昼长夜短，可适当晚睡（不晚于23点），天亮即起。午间11点至13点心经当令，闭目小憩30分钟可滋养心气、消解烦躁。

作息要点：
  • 入睡时间：不晚于23:00，最佳入睡时段22:30-23:30
  • 起床时间：6:00-7:00，接受清晨自然清气
  • 午睡：20-30分钟最佳，不宜过长以免进入深睡后醒来更疲惫
空调使用规范：
  • 温度设置26-28℃，与室外温差控制在5-8℃以内
  • 冷风切忌直吹头颈、胸背、腹部和膝关节
  • 出汗后先擦干汗水再进入空调房
  • 早晚开窗通风，让室内浊气排出
情志调摄：暑热最易扰心神，高温天里莫名心烦意乱即"情绪中暑"。应对之道：多听舒缓音乐，遇事缓几秒再回应。心态平和了，身体的燥热感也会随之减轻。
来源：《黄帝内经》素问·四气调神大论 / 包头市九原区中西医结合医院 / 广东省中医院

三伏天运动科学：微汗为度，忌大汗淋漓耗伤气血
P1运动科学节气专项

中医认为"汗血同源"，大汗淋漓会耗伤气血，加重暑天乏力气短。大暑运动核心为忌大汗，优先推荐慢走、八段锦、太极等温和项目，以身体微微出汗为标准。现代医学研究亦表明，持续高温热应激会激活HPA轴，导致皮质醇升高、肌肉分解。

运动建议：
  • 时间选择：清晨或傍晚凉爽时段，避开11:00-16:00高温时段
  • 运动项目：散步、慢跑、太极拳、八段锦、游泳
  • 强度标准：以微微出汗为宜，心率控制在合理范围
  • 运动后：不能马上冲冷水、吹冷风，避免寒湿侵入体表
  • 补水：运动前30分钟喝200-300ml温水，运动后及时补充含电解质饮料
减重提醒：三伏天虽代谢旺盛，但盲目节食或过度运动会损伤脾胃。湘雅医院罗湘杭团队2026年发表于Cell的研究显示，慢性热应激通过"皮肤-下丘脑轴"驱动内脏脂肪堆积与胰岛素抵抗。建议饮食拒绝极端节食，选择早晚凉爽时段有氧加力量训练，不追求暴汗。
来源：广东省中医院许锐教授 / 湘雅医院罗湘杭团队Cell研究 / 上海市消保委美丽健康专业办

三伏天冬病夏治：三伏贴与艾灸的黄金时机
P1经络调理冬病夏治

大暑正值三伏天中伏前后，是"冬病夏治"的黄金时机。通过三伏贴、艾灸等方式，借天地阳气最旺之时，将体内积攒的寒气与湿气排出体外，对呼吸道慢性病、脾胃虚寒等问题起到调理作用。

四穴常按，安然度伏：
  • 关元穴（脐下3寸）：温补脾肾，散寒止痛，适合手脚冰凉者
  • 足三里（外膝眼下3寸）：健脾和胃，祛湿化痰，增强脾胃运化
  • 阴陵泉（小腿内侧凹陷处）：健脾祛湿，缓解下肢沉重
  • 大椎穴（颈部第七颈椎棘突下）：温补阳气，驱寒散寒
委中穴清暑祛湿：委中穴位于膝盖后方腘横纹中点，为膀胱经合穴，可疏通全身经络气机，清泄暑热湿浊。坐位用双手拇指按压弹拨双腿委中穴，每侧30秒至1分钟，每日三遍。

操作要点：每日每穴揉3-5分钟，以酸胀感为宜。力度轻柔适中，以酸、胀、麻、热为佳，切忌暴力按压。避开腿部静脉曲张位置。

禁忌人群：孕妇及哺乳期妇女、药物成分过敏者、严重皮肤病患者不宜贴敷三伏贴。请在专业医师指导下使用。
来源：包头市九原区中西医结合医院 / 青岛市中医医院（海慈医院）/ 湖南中医药大学第一附属医院

夏季失眠科学调理：核心体温管理与昼夜节律校准
P1睡眠修复情志调摄

2026年《中国季节性睡眠白皮书》数据显示，全国近63.7%的成年人在6-8月出现典型夏季睡眠障碍——入睡延迟超45分钟、深睡时长缩水32%。《英国医学杂志》子刊研究指出，对代谢最友好的睡眠时长为7小时18分钟，睡眠时长与代谢健康呈倒U形曲线关系。

夏夜难眠三大根源：
  • 光照暴政：傍晚强光持续照射抑制褪黑素分泌，每接受1000lux光照15分钟，褪黑素延迟约22分钟
  • 热浪围城：室内湿度大于65%、气温大于28℃时散热效率骤降，核心体温需下降0.5℃以上才能启动深睡
  • 心火扰神：35℃环境下思维反刍率提升41%，琐事记忆强化效应增强2.3倍
5个零成本助眠法：
  • 体温管理：睡前90分钟用28℃温水湿毛巾轻敷颈侧、手腕、脚心（三大散热枢纽）
  • 腹式呼吸：吸4秒→屏2秒→呼6秒，5分钟即可
  • 固定起床时间：不依赖周末补觉，起床后尽快到自然光下校准生物钟
  • 睡前1小时远离屏幕：减少蓝光对褪黑素分泌的抑制
  • 代茶饮：莲子银耳汤清心安神；莲子心3克+淡竹叶5克代茶清心泻火；桑葚、酸枣仁、乌梅煮水收敛心神
午睡养心：中午11-13点心经当令，小憩20-30分钟养心阴、收敛浮阳，有效改善夜间睡眠质量。
来源：《英国医学杂志》子刊 / 中科院心理所 / 甘肃省第二人民医院心理危机干预科

三伏天脾胃虚寒体质：生姜护阳与家常祛湿药膳
P2体质对症饮食调理

三伏天阳气盛，人体阳气浮于体表，脾胃偏虚，暑湿容易困住脾胃，导致乏力、腹胀、大便黏腻、水肿。福建中医药大学附属康复医院高燕玲副主任医师建议，饮食调养以清暑祛湿、健脾养胃、护阳不贪凉为原则。

日常代茶饮（全家适用）：
  • 清暑祛湿茶：陈皮3g、茯苓5g、荷叶适量，开水冲泡代茶饮，平和祛湿不伤阳，缓解乏力、胃口差
  • 益气生津茶：太子参、麦冬、五味子煮水，补气止汗恢复体力，适合出汗多、易累者
  • 生姜红枣水：晨起小口饮用，驱散夜间寒湿，固护脾胃阳气
家常药膳：
  • 冬瓜白扁豆排骨汤：祛湿消肿、清热解暑，适合出汗多、身体困重、腿脚易肿者
  • 莲子百合小米粥：健脾安神、助睡眠，适合天热心烦失眠者
  • 冬瓜薏米汤：冬瓜带皮、炒薏米、少许瘦肉，利水祛湿不伤正气
苦寒之品须知：绿豆、凉茶性质寒凉，脾胃虚寒、体虚人群长期喝会损伤脾阳，越喝湿气越重。建议每周不超过3次，煮绿豆汤可加两三片生姜中和寒性，不宜冰镇。
来源：福建中医药大学附属康复医院高燕玲副主任医师 / 国家中医药管理局三伏天中医养生发布会

夏季时令蔬果营养解析：秋葵、红薯叶、三瓜的清补价值
P2营养学饮食调理

三伏天脾胃运化弱，低负担、高纤维、高水分的蔬菜是肠胃的"小假"。北京中医药大学东方医院刘洋主任提出三伏饮食原则"清补而不滋腻"，适当减量但不节食，优质蛋白仍需稳住。

三种时令蔬果营养数据：
  • 秋葵：每100g仅25千卡，膳食纤维1.8g，钙101mg（与牛奶相当）。黏性物质含可溶性膳食纤维和多糖，促进胃肠蠕动、护胃壁、增进食欲。性味淡寒，入肺脾肝经，适合三伏燥热上火、脾胃发沉、大便干结者。注意：黏液是精华，焯水时加盐和白醋锁色，不要洗掉
  • 红薯叶：每100g仅27千卡，蛋白质3.1g（超菠菜），钙180mg（超牛奶），β-胡萝卜素2220微克（满足每日维A需求80%以上），维生素B1/B2在叶菜中名列前茅
  • 三瓜清热化湿：苦瓜（清热除烦、控血糖）、丝瓜（清热利湿、美人水）、冬瓜（高钾低钠、控血压、利水消肿）
优质蛋白不可缺：每餐保证掌心分量的鱼虾、去皮禽肉、鸡蛋、豆腐。高温环境下蛋白质分解速率加快，不吃肉≠不要蛋白，只是不吃重油重荤的肉。

夏季肠道微生态养护：膳食纤维与短链脂肪酸的抗真菌新机制
P2肠道健康免疫防御

2026年7月，Cell子刊《Cell Host & Microbe》发表重磅研究：美国UT西南医学中心团队发现，肠道有益菌分解膳食纤维时产生的短链脂肪酸（丁酸、丙酸、乙酸），能有效抑制白色念珠菌的生长，机制为破坏念珠菌对葡萄糖的摄取能力并导致真菌细胞内酸化。

核心发现：
  • 丁酸和丙酸的抑制效果明显优于乙酸，产丁酸和丙酸的有益菌更关键
  • 短链脂肪酸不仅直接抑菌，还能促进更多产酸有益菌生长，形成"好菌越多、酸越多、坏菌越少"的良性循环
  • 拥有正常肠道菌群的小鼠中效果远好于无菌小鼠
养护肠道免疫力三件事：
  • 多吃膳食纤维：全谷物、豆类、蔬菜水果是好菌的"口粮"，尤其菊粉、低聚果糖等水溶性膳食纤维喂养效果更好。三伏天可多吃秋葵（黏液含可溶性纤维）、红薯叶、豆角
  • 别滥用抗生素：抗生素会杀灭有益菌，打破菌群平衡，给真菌可乘之机
  • 关注肠道整体健康：菌群多样性越高，产酸菌越丰富，肠道防线越牢固。长期外卖、熬夜、压力大都会让菌群"缩水"
适用人群：夏季反复腹胀、消化不良、免疫力低下者；长期外卖饮食的都市职场人群。
来源：Cell Host & Microbe 2026年7月 / UT西南医学中心 / 《Gut Microbes》2025年中国成年人横断面研究

夏季皮肤防护：紫外线双重伤害与硬防晒优先策略
P3皮肤防护知识拓展

地表95%的紫外线为UVA，是皮肤变黑、长皱纹、老化的元凶。高温会放大紫外线伤害：刺激黑色素分泌、扩张皮下毛细血管、引发日晒炎症，带来晒红、变黑、快速老化三重损伤。长期累积更会破坏皮肤细胞DNA，提升皮肤疾病风险。

完整防晒方案（硬防晒优先）：
  • 时间管控：每日10:00-16:00是紫外线高峰，能不外出则居家
  • 硬防晒三件套：宽檐帽、UPF50+专业防晒衣、黑胶遮阳伞
  • 地面反光注意：草地反射1%紫外线，水面20%，雪地高达80%——硬防晒+防晒霜搭配才稳妥
  • 衣物选择：宽松浅色棉麻丝面料，环境温度超体温时光膀子反而在吸热
四类人群防晒须做到极致：
  • 光敏皮肤病患者（红斑狼疮、日光荨麻疹等）
  • 医美术后人群（激光、祛斑后暴晒极易反黑）
  • 中老年人群（皮肤脆弱，常服光敏药物）
  • 户外工作、长期通勤人群
晒后修复：含神经酰胺或透明质酸的医用保湿剂可修复受损屏障。儿童皮肤娇嫩，长时间暴晒后易引发皮温升高、泛红甚至蜕皮，需格外注意。
来源：首都医科大学附属首都儿童医学中心皮肤科 / 《2026中国城市居民防晒消费白皮书》
