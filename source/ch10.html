大暑五运六气：湿热交蒸格局下的健脾核心策略

2026丙午年大暑处于六气"四之气"阶段，主气太阴湿土，客气少阳相火，火蒸湿动，形成高温高湿的闷热气候。全年水运太过的寒水底色仍存，大暑虽酷热，但时常骤降暴雨，闷热过后骤凉，形成"外湿内热"环境：日间酷暑耗津液，雨后湿邪困脾胃，冷热交替极易诱发不适。

P0 · 脏腑养护 脾胃调理

湿困脾土：大暑脾胃运化低谷期的饮食架构

大暑湿热并重，脾喜燥恶湿，湿邪最易困阻脾胃运化功能。临床门诊显示，大暑前后消化不良、腹胀腹泻、食欲全无的患者显著增多。山东中医药大学附属医院消化内科主任医师王伟明确指出，大暑饮食调养需坚守"清而不过寒，补而不过腻"的核心准则。

常见误区：不少人认为夏季清淡饮食就是单一喝粥、吃素，这会导致蛋白质摄入不足、体质下降、不耐暑热。正确做法是"清淡不等于寡淡"——清淡的核心是易消化、低油腻，而非舍弃营养。

明代万全《育婴家秘》"若要小儿安，常带三分饥与寒"，放在大暑所有人群都适用："三分饥"不是饿肚子，是别吃太饱，脾胃才运化得开；"三分寒"不是受冻，是别捂太严实也别过于贪凉。元代忽思慧《饮膳正要》："夏月宜食清淡之物，不可过食肥甘厚味。"

具体建议：
饮食：早餐温热（山药小米粥/薏米茯苓粥），午餐七分饱（搭配冬瓜老鸭汤），晚餐清淡少油（凉拌马齿苋+小米糊）。
食材优选：清热祛湿类（冬瓜、绿豆、薏米、荷叶、苦瓜、丝瓜）；健脾养胃类（山药、莲子、小米、南瓜、茯苓、白扁豆）；益气生津类（鸭肉、莲藕、银耳、百合）。
禁忌：忌烧烤油炸、重油重辣助湿生热；忌冰镇西瓜当正餐直伤脾阳。

P0 · 饮食禁忌 中医食疗

"清而不过寒，补而不过腻"——大暑药膳三方的精准配伍

大暑饮食之道贵在平衡：既要清热祛湿，又要顾护脾胃、温养阳气，做到清补而不滋腻，温养而不助火。以下三方分别针对清热祛湿、健脾化湿、养心安神三个方向。

方一 · 冬瓜薏米老鸭汤（清暑不寒、祛湿不燥）：冬瓜性微寒利水消肿，薏米健脾祛湿，老鸭性凉滋阴养胃。三者同煲，清而不伤阳，祛湿不耗气。适合全家老少。

方二 · 荷叶薏米绿豆粥（清暑化湿、养心安神）：鲜荷叶升清降浊，炒薏仁健脾渗湿，绿豆清热解毒，加3粒鲜莲子养心安神，对抗夏季心烦失眠。文火慢熬40分钟。

方三 · 姜枣茶（春夏养阳、温中散寒）：生姜4片、红枣6颗（去核）、枸杞一把煮水。立夏到三伏前饮用最佳，补体内阳气之虚以温中，助阳气发散以排寒。

具体建议：
适用人群：湿热困脾者选方一；心烦失眠者选方二；空调房久待、体寒怕冷者选方三。
禁忌：大便燥结、气滞火大者不宜姜枣茶加党参；脾胃虚寒者不宜多食苦瓜等寒凉之物；姜枣茶体寒怕冷者可加几粒花椒增强祛寒湿之效，但容易上火者保留生姜皮（留姜皮则凉、去姜皮则热）。

P1 · 现代医学 科学补水

高温天只喝白水不够：电解质平衡的科学补水指南

高温酷暑环境下，人体流失的不只是水分，还有大量维持身体运转的电解质。夏季汗液中裹挟着钠、钾等多种电解质成分，大量出汗后只补白水，会造成体内电解质持续稀释、流失失衡，这是高温补水最核心的误区。长期如此，可能出现"低渗性脱水"——身体水分总量充足，但电解质浓度失衡，细胞无法正常吸收和利用摄入体内的水分。

肾脏是人体电解质平衡的核心调节器官。当体内水分过多、电解质浓度过低时，肾脏需要超负荷工作，不断调节渗透压，反复过滤多余水分、留存稀缺电解质，长期透支会引发肾脏代谢损伤。《美国医学会杂志》（JAMA）对照研究显示：饮用同等量的电解质水与纯净水，4小时后电解质组的体内水分贮存量达48%，高于纯净水组的28%。

中暑三级预警信号：先兆中暑（头晕乏力、口干虚汗、注意力不集中）；轻症中暑（体温38℃以上、面色潮红或苍白、心跳加快）；重症中暑/热射病（体温≥40℃、皮肤干热无汗、意识模糊、抽搐昏迷，死亡率20%-70%）。

具体建议：
饮水：健康成年人每日1500-2000ml，每20-30分钟小口饮用100-200ml。不等口渴再喝，不一次猛灌。中等强度活动每15-20分钟饮水200-300ml。
补充电解质：出汗较多时搭配淡盐水、口服补液盐或含电解质饮品。日常饮食中补钾——适量吃香蕉、橙子、土豆、菠菜、菌菇、豆制品。
禁忌：忌自行乱补钾制剂（可致高钾血症，肾功能不全者尤其谨慎）；忌输液当解暑方式（补液过快过多可致心悸、心律失常甚至急性心衰）。

P1 · 经络调理 穴位按摩

大暑日常按揉四穴：阴陵泉、足三里、内关、曲池

大暑湿热并重，日常穴位按揉是居家调理的有效手段。以下四穴分别针对祛湿、健脾、安神、清热四个方向，每穴轻柔按揉3-5分钟，早晚各一次。

阴陵泉（祛湿第一穴）：位于小腿内侧，胫骨内侧髁后下方凹陷处。为足太阴脾经合穴，是脾经气血汇聚的"泉眼"。按揉能强健脾胃、加速运化，把滞留体内的湿毒废水充分排出。改善身重、水肿、湿气缠身。

足三里（健脾和胃要穴）：位于外膝眼下四横指、胫骨外侧一横指处。为足阳明胃经合穴，强健脾胃、改善暑天食欲不振、腹胀、体虚乏力。临床也常在此穴注射免疫复合物，发挥穴位与药物协同作用。

内关穴（清心安神）：位于腕横纹上三横指、两筋之间。为手厥阴心包经络穴，通阴维脉。宽胸理气、和胃降逆、安神定志。缓解心慌烦躁、情绪中暑。

曲池穴（清热解暑）：屈肘，肘横纹外侧端凹陷处。为手阳明大肠经合穴，清热泻火、疏风解暑。改善身热烦躁、口干上火、湿热皮肤瘙痒。

具体建议：
操作：每穴拇指轻柔按揉3-5分钟，早晚各一次，酸胀感渗透为佳。
适用人群：湿热困脾者重点按阴陵泉+足三里；心烦失眠者加按内关；湿热皮肤问题者加按曲池。
补充：出汗多气虚者，可配合艾灸关元、复溜二穴。倪海厦指出，复溜为肾经母穴，关元灸之可温阳化水，使体内多余积水气化排出，减少炎症发生。

P1 · 运动科学 高温运动

高温运动安全指南：心率管理与五大常见误区

大暑期间运动需格外科学。医学研究表明，高温环境下进行剧烈运动时，心血管系统面临双重压力：皮肤血管扩张散热，肌肉需血量增加，心脏需大幅提高输出量，心率可从静息70次/分钟升至160-180次/分钟。高温环境还会加剧体内自由基产生，损伤细胞膜及心肌组织。

五大常见误区：①正午暴晒运动（10:00-16:00紫外线最强，核心体温易突破38.5℃）；②运动后猛灌冰水（低温刺激致肠胃痉挛）；③忽视湿度影响（湿度>60%时汗液蒸发效率下降60%，运动10分钟即可能中暑）；④空腹运动降糖（低血糖发生率比常温高40%）；⑤运动后冷水冲澡（血管急剧收缩、乳酸代谢受阻）。

心率管理公式：最大心率估算值=220-年龄；中高强度有氧运动目标心率区间=最大心率×60%~85%。以30岁为例，最大心率约190次/分钟，适宜运动心率区间为114~162次/分钟。

具体建议：
时间：清晨5:00-7:00或傍晚18:00后，日照减弱、紫外线强度降低50%。
场地：选择室内有遮挡或室外有树荫处，避免水泥地、柏油路等吸热路面。
补水：运动前1-2小时饮500ml淡盐水；运动中每15-20分钟补150-200ml电解质水；运动后少量多次饮含钾饮品。
装备：浅色宽松速干面料，透气网面运动鞋+吸汗棉袜，防晒霜每2小时补涂，宽檐帽+太阳镜。
特殊人群：老年人以太极拳、八段锦为主，时间30分钟左右；高血压患者避免突然站立；糖尿病患者随身携带糖果。
禁忌：忌大汗淋漓后立刻冲冷水澡或进入低温空调房（先静坐十分钟，擦干汗液，温水冲洗10分钟以内）。

P1 · 日常起居 子午觉

睡好"子午觉"：大暑心火旺盛期的睡眠调摄

《黄帝内经》言："阳气尽，阴气盛，则目瞑；阴气尽而阳气盛，则寤矣。"大暑心火最旺，人易烦躁易怒、心慌焦虑、失眠多梦。中医认为"眠为养生之首"，睡眠与人体阴阳气血盛衰及脏腑功能协调密切相关。2025年中国睡眠健康调查报告显示，我国成年人睡眠困扰率高达48.5%。

子午觉法则：子时（23:00-1:00）胆经当令，阳气初生，必须入睡，最能养阴；午时（11:00-13:00）心经气血旺盛，小憩15-30分钟可养阳，事半功倍。亥时（21:00-23:00）三焦经当令，通调百脉，宜静心准备入睡。春夏可稍晚至23:30入睡，秋冬需22:30前就寝。

睡前导引：睡前1小时远离手机（蓝光抑制褪黑素分泌），温水泡脚10分钟引火归元。可按揉神门穴（宁心安神，睡前按揉1-2分钟）、涌泉穴（引火归元、助眠降压）、三阴交（调肝脾肾、养血安神）。

具体建议：
作息：23点前入睡，清晨6-7点起床；午时小憩15-30分钟，不超过1小时。
食疗助眠：酸枣仁小米粥（炒酸枣仁10g+小米50g睡前1小时食用）；桂圆百合茶（3颗桂圆+10g百合煮水）。
环境：卧室安静黑暗，室温控制在26℃左右，空调风口避开肩颈腰腹。
禁忌：忌睡前饮酒（打断深度睡眠）；忌睡前刷手机；忌晚餐过饱；忌午后补觉超过30分钟影响夜间入睡。

P2 · 情志调摄 静心养神

"情绪中暑"的识别与清心降火四法

暑热最易扰心神，使人焦躁不安，所谓"暑易入心"。大暑火气极旺，心火亢盛，人易焦躁易怒、失眠多梦、口舌生疮，此即"情绪中暑"。《黄帝内经》载："使气得泄，若所爱在外，夏气之应，养长之道也。"心血管压力在闷热天气下较大，年纪大的人一旦情绪激动，容易损伤心脏。

夏季雨水和炎阳交替，闷热天气让人心情烦躁，心血管压力较大。静为躁君，心灵经常与清静为伴，健康才能有保障。中医讲"肝藏魂、心藏神"，情绪郁结易致"肝郁化火、心神不宁"，引发入睡困难。

具体建议：
情志：平日遇事平和自持，少焦躁动怒。闲暇静坐调息、赏荷听雨、练字阅书、聆听舒缓乐曲。
茶饮：清心祛湿茶——麦冬、淡竹叶、荷叶、茉莉、陈皮，清心降火、疏肝醒脾。
穴位：按揉内关穴宽胸理气、安神定志。
禁忌：忌大喜大悲；忌长期思虑过度伤脾；忌熬夜使交感神经持续兴奋。
来源：《黄帝内经》素问 / 沈阳市第六人民医院中医科 / 天津中医药大学第二附属医院

P2 · 常见病预防 防阴暑

警惕"阴暑"：空调冷热骤变诱发的心脑血管风险

大暑时节，室外高温下人体毛孔张开、阳气外浮，进入空调房后温度骤降，毛孔快速闭合，寒湿易侵入体内，即常说的"空调病"或"阴暑"。表现为颈肩僵硬、头痛恶心、关节冷痛，是夏季骨关节不适高发的重要诱因。

某医疗机构夏季临床统计显示，三伏天接诊的中老年心脑血管突发不适患者中，超六成发病诱因是冷热骤变。骤然降温让扩张的体表血管瞬间收缩，血管压力急剧升高，心脏负荷瞬间飙升。本身有高血压、动脉硬化的老人，可能诱发心梗、脑梗等严重问题。冷热交替还会刺激呼吸道黏膜，导致免疫力短暂下降，易诱发感冒、支气管炎。

具体建议：
空调：温度不低于26℃，风口避开肩颈、腰腹、脚踝；遵循"夏不露脐"原则。
降温方式：出汗后先静坐休息十分钟，擦干体表汗水，用温水洗澡（10分钟以内），全程规避快速冷热刺激。
通风：室内早晚开窗通风，正午密闭隔热除湿。
禁忌：忌大汗后立刻冲冷水澡；忌空调温度低于26℃直吹；忌睡凉地板。
来源：多地三甲医院夏季临床统计 / 天津中医药大学第二附属医院

P2 · 营养学 夏季补钾

大暑补钾：被忽视的夏季营养关键

夏天排汗多，身体无机盐大量排出体外。人们常以淡盐水补充盐分而忽略补钾。钠钾失衡，容易导致心脑血管疾病。钾元素轻微缺失，会直接影响肌肉收缩和体能状态，让人整日昏沉无力。钠元素失衡则打乱身体渗透压，出现头晕、困倦、精神萎靡。

钾参与心脏跳动、肌肉收缩和神经传导。大量出汗、户外劳动、剧烈运动后，如果只大量喝白水，可能出现"水补了、盐没补"的情况，轻者乏力头晕心慌腿抽筋，重者出现低钠、低钾、热痉挛、热衰竭甚至心律失常。需要注意的是，钾制剂使用不当可导致高钾血症，出现乏力、麻木、心率减慢、心律失常，严重者危及生命，尤其肾功能不全者更需谨慎。

具体建议：
食补优先：喝茶、吃菠菜、番茄、红薯、香蕉、橙子、菌菇、豆制品、瘦肉。
适用人群：户外工作者、运动人群、老年人、儿童、孕妇，以及心血管病、肾病、糖尿病患者（需遵医嘱）。
禁忌：忌自行乱补钾制剂；忌大量冰饮诱发胃肠痉挛加重电解质丢失；忌输液当解暑方式。
来源：怀化市中心医院鹤城院区 / 中国营养学会膳食指南

P2 · 小儿养生 儿童调护

大暑小儿调护：扶阳祛湿的儿童专属方案

大暑是全年暑湿之邪最盛的考验期，更是中医"冬病夏治"的黄金冲刺期。对于正处于生长发育旺盛期的孩子，大暑过后便是立秋，天地间阳气将由鼎盛转向收敛。儿童体温调节能力相对较弱，脾胃功能娇弱，高温天气容易体温升高导致中暑，炎热天气使食欲下降、消化能力减弱。

佛山市妇幼保健院指出，大暑期间可结合小儿推拿和节气调护，帮孩子扶助阳气、祛除伏寒。儿童大暑常见问题包括中暑、痱子、食欲不振、上火（咽喉肿痛、便秘）。小儿脾胃更加薄弱，大暑期间腹泻的孩子十个有八个是冰西瓜、冰酸奶、凉拌菜所致。

具体建议：
饮食：益气养阴多安排大枣、蜂蜜、莲藕、百合、乌梅、银耳；健脾利湿用薏米、赤小豆、芡实、山药、白扁豆熬粥；老鸭汤清润不伤儿。
作息：晚上11点前睡着，中午眯20-30分钟"养心午觉"。
运动：早上7点多或傍晚6点后散步、游泳，微微出汗排出湿邪，但避免正午11点-下午4点在大太阳下活动。
禁忌：忌冰棒冰粥直伤脾阳；忌隔夜凉菜、放久的水果；忌一身汗冲冷水澡；忌空调风口直吹后脖和小肚脐。
来源：佛山市妇幼保健院 / 《育婴家秘》万全
