P0 · 核心 节气养生 清暑化湿

大暑湿热鼎盛：益气养阴、清暑化湿为当前养生第一要务

大暑是全年暑气最盛、湿气最重的节气，2026年为丙午年，水运太过，大暑步入四之气，主气客气均为太阴湿土，"双重湿土"叠加使湿热交蒸之势更甚往年。暑性升散，易耗气伤津，使人出汗过多、疲倦乏力、口干舌燥；湿性黏滞，易困脾阳，导致脾胃运化失常，出现腹胀、大便不爽、头重如裹。中医强调"顺时而养"，养生核心在于益气养阴、清暑化湿、固护阳气，切忌一味清火、贪凉猛冷，否则会损伤脾阳、困住寒湿，导致伏天体虚、秋后多病。

医理讲解：大暑阳气浮于肌表，腠理开泄，汗出淋漓，津液大量耗伤，气随津脱，心阳易损。"津血同源"，汗为心之液，大汗不仅伤津，更伤心血。老年人与心血管疾病患者尤当警惕暑热耗气伤心，最易引发中暑"脱证"。养护需清补兼施，温和清暑，不可过寒伤阳。
具体建议：
饮食：多吃山药、芡实、百合、银耳、冬瓜等时令食材，养阴润燥、健脾固气；推荐百合银耳莲子汤（养阴生津）、山药芡实小米粥（健脾补虚）、荷叶陈皮温水饮（理气祛湿）。
起居：夜卧早起，不晚于23点入睡；午时心经当令，午休15-30分钟补元气。
禁忌：严格控制冰饮、冰西瓜、冰镇甜品；少吃重油重辣、烧烤卤味、甜腻零食。

P0 · 核心 脾胃养护 健脾祛湿

三伏天脾胃养护：外热内寒，清补兼施守好脾胃阳气

三伏天最大的特点是"外热内寒"——天气越热，人体阳气越往体表跑，毛孔张开、大量出汗，五脏六腑里面反而是一年中最虚寒的时候。尤其是脾胃，阳气亏虚、运化能力减弱。加上暑气和湿气双重夹击，湿气困住脾胃，人就容易没胃口、犯困、肚子胀、大便黏腻。山东中医药大学附属医院消化内科主任医师王伟明确指出，大暑饮食调养核心原则是"清而不过寒，补而不过腻"，清热解暑与健脾祛湿兼顾，摒弃极端养生误区。高温环境下人体能量与蛋白质消耗激增，需合理摄入鱼、虾、禽肉、蛋类、豆制品等优质蛋白，避免因营养单一导致体质下降。

核心要点：
1. 清淡饮食重均衡，拒绝寡淡补营养——核心是易消化、低油腻，而非舍弃营养、饮食单一。
2. 消暑切莫贪凉，守好脾胃阳气——大量生冷食物进入肠胃，会直接刺激胃肠道黏膜，损伤脾胃阳气，极易引发腹胀、腹痛、腹泻。
3. 结合"春夏养阳"理念，烹饪可适量添加生姜、陈皮、紫苏等辛温食材，温补脾胃、提振食欲。
4. 忌口厚味重油，严守饮食卫生——烧烤、油炸、重口味食物会加重脾胃负担，助湿生热。
推荐食疗：陈皮冬瓜薏米老鸭汤（滋阴补虚不燥热，利水祛湿不伤阳）；五指毛桃土茯苓瘦肉汤（健脾祛湿）；陈皮茯苓水（陈皮3g+茯苓5g代茶饮，健脾祛湿、缓解夏日困倦腹胀）。

P0 · 核心 冬病夏治 三伏贴

冬病夏治三伏贴：中伏20天为全年调理黄金窗口，须辨证施治

2026年三伏天为40天加长版，中伏时段7月25日至8月13日共20天，是全年阳气最旺盛、调理效果最好的黄金时期。三伏贴是冬病夏治中最经典的外治法，选用辛温祛寒、通经活络的药物制成贴敷膏，贴于对应穴位，借助天地阳气驱散体内寒邪。天津中医药大学第一附属医院治未病健康管理中心主任董桦指出，三伏天自然界阳气隆盛，人体腠理开泄、气血汇聚体表，"天之阳、人之阳、药之阳"三者相合，调理往往事半功倍。但三伏贴并非"万能贴"，必须由专业中医师辨证选穴，不可自行贴敷。

适用人群：慢性呼吸系统疾病（支气管炎、哮喘、慢阻肺）、过敏性鼻炎、反复感冒；颈肩腰腿痛、关节怕冷、寒湿痹痛；脾胃虚寒（慢性腹泻、腹胀、消化不良）；宫寒痛经、手脚冰凉、免疫力低下。

禁忌人群：①孕妇及2岁以下幼儿；②正在发烧、咽痛、咳黄痰的热性病患者；③严重皮肤过敏或贴敷部位有破损者；④阴虚火旺者（常年口干舌燥、面红潮热、舌红少苔）。

贴敷规范：成人每伏连贴3天，每天1次，每次6-8小时；儿童2-4小时。贴后忌食生冷辛辣、海鲜发物，避免冷水冲澡、长时间吹冷风。感觉灼热刺痒立即揭下，切勿强忍。

P1 · 重要 运动科学 高温防护

高温运动防护四原则：科学补水、控制强度、避开正午暴晒

国家体育总局体育科学研究所国民体质与科学健身研究中心发布高温运动防护四点建议。中暑、脱水、电解质紊乱是夏季运动爱好者常面临的风险，高温高湿环境下人体产热与散热平衡被打破，严重时可发展为热射病，病死率较高。高温运动核心是"顺应四时，而非勉强坚持"。当气温大于32℃且湿度大于60%时，应果断暂停户外剧烈运动。热痉挛→热衰竭→热射病是高温急症三个递进阶段，出现头晕、心慌、恶心、大量出汗却发凉、或不出汗但皮肤干热时，必须立即停止运动移至阴凉处。

四项防护要点：
1. 科学补水：运动前30分钟喝200-300ml温水；运动中每15-20分钟补水100-150ml（少量多次）；超1小时运动必须补充含钠钾电解质饮料；运动后每减轻0.5公斤补水500-700ml。严禁运动后猛灌冰水，5-15℃常温饮品最利于吸收。
2. 防晒降温：避开10:00-16:00时段，选择6:00-8:00或18:00后运动；穿浅色透气速干服，戴宽檐帽、运动墨镜。
3. 强度控制：较日常强度降低20%-30%；单次户外运动控制在60分钟内，中间休息15分钟。
4. 免疫力维稳：运动后擦干汗休息15分钟再温水洗澡；每周运动3-4次，每次30-60分钟；运动后1小时内补充"碳水+蛋白质"（如酸奶+香蕉）。
禁忌提醒：高血压、糖尿病、冠心病患者高温户外运动前务必咨询医生；感冒、发烧、腹泻期间停止运动，避免诱发心肌炎；橙色、红色高温预警天气应改为室内运动或休息。
来源：国家体育总局体育科学研究所国民体质与科学健身研究中心

P1 · 重要 睡眠调理 夏季失眠

夏季睡眠障碍：高温高湿致深睡缩水32%，物理降温优于药物助眠

2026年《中国季节性睡眠白皮书》数据显示，全国近63.7%的成年人在6-8月出现典型夏季睡眠障碍——入睡延迟超45分钟、NREM深睡时长平均缩水32%、夜间觉醒次数增加2.4倍。夏季失眠有三大核心诱因：光照暴政（傍晚强光持续照射抑制松果体褪黑素分泌）、热浪围城（室内湿度大于65%、气温大于28℃时核心体温居高不下，而深度睡眠启动需核心体温下降0.5℃以上）、心火燎原（高温升高皮质醇水平，睡前思维反刍率提升41%）。专家强调，夏季失眠优先采用非药物自然调理方案，避免长期依赖高剂量外源褪黑素导致自身分泌抑制。

五项零成本自然助眠法：
1. 体温管理法：睡前90分钟用28℃温水湿毛巾轻敷颈侧+手腕+脚心（三大散热枢纽），配合5分钟腹式呼吸（吸4秒→屏2秒→呼6秒），帮助核心体温下降。
2. 光照调节：睡前2小时减少屏幕蓝光暴露，傍晚18:00后每接受1000lux光照15分钟，褪黑素分泌延迟约22分钟。
3. 室温控制：卧室保持26℃左右，湿度50%-60%，避免空调直吹。
4. 情志调摄：暑热扰心神，可临窗听雨、读轻松书籍转移注意力；按揉太冲穴（足背第一、二跖骨间）每次2分钟疏肝解郁。
5. 作息规律：23:00前入睡，清晨6:00左右起床，午间小憩15-30分钟养心阴。

P1 · 重要 肠道健康 膳食纤维

Cell子刊重磅研究：膳食纤维经肠道菌群代谢产生短链脂肪酸，可抑制致病真菌

2026年7月，Cell子刊《Cell Host & Microbe》发表美国UT西南医学中心团队重磅研究：肠道有益菌分解膳食纤维时产生的短链脂肪酸（丁酸、丙酸、乙酸），能有效抑制白色念珠菌的生长。机制为短链脂肪酸破坏念珠菌对葡萄糖的摄取能力使其"饿肚子"，同时导致真菌细胞内部酸化，代谢和生长被迫减缓甚至停滞。丁酸和丙酸的抑制效果明显优于乙酸。动物实验还揭示了一个"正反馈"现象：短链脂肪酸不仅直接抑菌，还能促进更多产酸有益菌生长，形成"好菌越多→酸越多→坏菌越少"的良性循环。这意味着养好肠道菌群本身就是增强抗真菌能力的过程，对夏季易发念珠菌感染的女性尤其重要。

日常养护三要点：
1. 多吃膳食纤维：全谷物、豆类、蔬菜水果是有益菌的"口粮"，含丰富益生元。尤其是菊粉、低聚果糖等水溶性膳食纤维，喂养效果更佳。
2. 避免滥用抗生素：抗生素会杀灭有益菌，打破菌群平衡，给真菌可乘之机。
3. 关注肠道整体健康：菌群多样性越高，产酸菌越丰富，肠道防线越牢固。长期外卖、熬夜、压力大都让菌群"缩水"。
来源：Cell Host & Microbe（2026年7月）｜美国UT西南医学中心团队

P2 · 常规 情志调养 静心养神

暑热扰心神：心静自然凉，情志调摄是伏天养生不可忽视的一环

中医认为"夏气通心"，暑热最易扰心神，让人焦躁不安。2026年中科院心理所实验发现：35℃环境下，受试者睡前思维反刍率提升41%，对琐事的记忆强化效应增强2.3倍。高温显著升高皮质醇与去甲肾上腺素水平，白天积压的焦虑情绪往往在深夜集中爆发，形成"越热越烦躁→越烦躁越失眠→越失眠越焦虑"的恶性循环。中医养生强调大暑时节"心静自然凉"，情志调摄与饮食起居同等重要。保持心态平和，减少无谓的烦躁消耗，是三伏天养心护阳的关键。

具体建议：
情志：可临窗观雨、听蝉鸣，或读一本轻松的书转移注意力；每日傍晚静坐，鼻吸口呼，呼气时轻念"吹"字（音同"催"），重复7次，可滋养肾气、缓解暑热乏力。
穴位按摩：按揉太冲穴（足背第一、二跖骨间）每次2分钟，左右各1次，疏解肝郁、缓解闷热导致的头痛眩晕。
香薰祛湿：用苍术、艾叶各10g煮水放凉后装入喷瓶喷洒室内，既祛湿又安神。
运动：八段锦"调理脾胃须单举"，清晨或傍晚练习，左右臂交替上举配合深呼吸，促进脾胃运化。"拍肘窝"排毒，用空心掌轻拍曲池穴附近，每次30下，排出心经暑湿郁热。
来源：中科院心理所实验数据｜弥渡县中医医院治未病科大暑养生指南

P2 · 常规 食疗方 三豆饮

改良三豆饮与伏天食疗：并非人人适合喝绿豆汤，辨体质选食材

绿豆汤是夏季消暑标配，但中医提醒：绿豆性凉，脾胃虚寒者喝多了反而伤脾阳。专家推荐"改良三豆饮"——将绿豆、赤小豆、黑豆各20克，再加3颗去核红枣和5克陈皮。黑豆缓减绿豆寒性，红枣和陈皮温中理气，既能清热解暑，又护住了脾胃阳气。所有豆类浸泡2小时，煮至开花，喝汤吃豆，避免加过多糖。三伏天调养并非"千人一方"，盲目跟风吃瓜、贴敷反而可能损伤脾胃。

分体质选瓜三原则：
1. 冬瓜：利水消肿，适合水肿、小便黄赤者。炖汤时连皮带籽利水效果更佳，务必加几片生姜或陈皮中和寒性。
2. 丝瓜：清热化痰，富含B族维生素。只需刮掉表面粗皮保留皮下青层，既保留纤维素又增强清热功效。
3. 苦瓜：清心火，适合口舌生疮、心烦易怒者。不宜空腹生吃，焯水后急火快炒减苦又不过寒。血糖偏高者搭配木耳或鸡蛋同食。

核心原则：每道瓜菜出锅前撒一小把白胡椒粉或姜末，可有效抵消凉性，老少皆宜。脾胃虚弱者推荐白扁豆（健脾化湿第一豆），提前炒至微黄再煮粥，健脾之力更强且不易胀气。

P2 · 常规 皮肤防护 防晒修护

夏季护肤：紫外线致85%皮肤光老化，内调外防护双管齐下

世界卫生组织旗下国际癌症研究机构（IARC）2026年更新报告揭示：长期无防护暴露于UVA/UVB辐射下，与高达85%的皮肤光老化问题（松弛、深纹、顽固色斑）存在直接因果关联。夏季紫外线强度翻倍，三伏天暑湿之气盛行，肌肤面临多重危机：外油内干（油脂过度分泌锁不住水分）、炎性爆痘（体内湿热郁结加毛孔堵塞）、光老化加速（UVA穿透损伤胶原）、屏障脆弱敏感（冷热温差大导致泛红刺痛）。中医认为"体内湿气不除，面部油腻暗沉不止"，外在皮肤问题与内在脾胃湿热密切相关。

内调外防护双策略：
内调：健脾祛湿，从根源改善湿热体质。多吃薏米、赤小豆、茯苓等祛湿食材；减少高糖高脂食物，避免湿热内生加重皮肤炎症。
外防护：

P2 · 常规 湿邪调理 分部辨证

中伏分部位祛湿：湿邪不同脏腑表现各异，辨证调理更精准

中伏20天是全年气温最高、湿度最大的时段，湿气弥漫，湿邪易侵入人体各个脏腑。不同部位湿气淤积会引发对应的不适，针对性祛湿、辨证调养才能从根源调理体质。中医将湿邪分为脾胃湿、肝胆湿、肺脏湿、肾脏湿、心气湿五类，各有典型表现和调理方向。2026年中伏养生核心讲究清热祛暑、益气养阴双向兼顾，重点深耕祛湿调养，同时规避寒邪侵袭。

五类湿邪辨证调理：
1. 湿在脾胃：食欲不振、腹胀腹痛、大便不成形、浑身困重乏力。调理：健脾和胃、化湿和中。宜食山药、薏米、红豆、白扁豆、冬瓜；忌辛辣油腻、生冷寒凉。
2. 湿在肝胆：失眠多梦、暴躁易怒、口苦口臭、面部油腻长痘。调理：疏肝利胆、清热化湿。宜食玫瑰花、薄荷、酸枣仁、绿豆；杜绝熬夜、过量饮酒。
3. 湿在肺脏：反复咳嗽、痰多黏稠、胸闷气短。调理：宣肺化痰。宜食金桔、梨子、百合、杏仁；保持室内通风。
4. 湿在肾脏：腰膝酸软、手脚冰凉、夜尿频繁、精神萎靡。调理：补肾利水、温阳化气。宜食枸杞、黑大豆、桑葚；作息规律不熬夜。
5. 湿在心气：焦虑烦躁、健忘乏力、心慌心悸。调理：祛湿安神、清心除烦。宜拔罐、艾灸、刮痧疏通经络；清淡少油少糖饮食。

P2 · 常规 起居作息 伏天养命

伏天起居两大"养命法"：晒背黄金窗与睡前温水泡脚

三伏天虽热，却是"冬病夏治"借天时养身的最佳窗口。中医推荐两项简便高效的伏天养生法，无需花费即可补阳气、祛陈寒、改善睡眠。晒背有"黄金窗"：早上7-9点背对太阳晒15分钟，可补阳气、祛陈寒。此时阳光温和，背部膀胱经和督脉循行，接受温和日照能温通经络。但中午11点至下午3点严禁暴晒，以免中暑伤阴。睡前温水泡脚：用40℃左右温水，加一小把花椒或艾叶，泡至微汗即止（不超过15分钟），能引火下行，改善夜间烦躁和失眠，比喝凉茶更安全。这两项方法简单易行，适合全家日常坚持。

注意事项：
1. 晒背时长不宜超过15分钟，以背部微微发热为度，不可追求大汗。
2. 泡脚水温不超42℃，时间不超15分钟，泡至微微出汗即可，大汗反而耗气伤津。
3. 空调温度建议设26℃以上，避免冷风直吹咽喉、后心、腰腹。
4. 出汗后不要立刻冲凉水澡，毛孔张开时冷水会致寒气直入，应擦干休息半小时再温水洗澡。
5. 23:00前入睡养护肝脾，三伏熬夜最易上火伤阴，减少心烦燥热。

P3 · 拓展 中医外治 艾灸拔罐

三伏中医外治祛湿固本：艾灸足三里、拔罐膀胱经，借势养阳

大暑正值三伏天中伏前后，是"冬病夏治"的关键期，也是中医外治法发挥效力的最佳时机。通过拔罐、艾灸、推拿按摩等传统疗法，可疏通经络、排出湿浊、调和气血。大暑暑湿郁滞体内，气血运行不畅，易引发颈肩腰背酸胀、浑身沉重乏力。专业推拿手法可疏通周身经络、放松紧绷肌肉，适合肌肉劳损、颈腰椎不适、夏季疲劳困倦人群。三伏天"续力"阶段，可进行三伏贴、三伏灸等治疗，借助天地阳气驱散体内寒邪，为秋冬体质打好基础。

三种外治法及适用：
1. 艾灸：取足三里、中脘、关元穴，温脾化湿，一周2-3次。适合脾胃虚寒、手脚冰凉、免疫力低下者。上火人群（口苦、舌苔黄）减少频次。
2. 拔罐：每周1次在背部膀胱经（脊柱两侧）走罐或留罐，疏通经络、排出湿浊。适合湿气重、肩颈僵硬、身体困重者。皮肤有破损、出血倾向者禁用。
3. 推拿按摩：调和气血，疏通经络，适合夏季疲劳困倦、颈肩腰背酸胀人群。

日常可自行操作：按揉足三里（外膝眼下四横指）每次3-5分钟健脾益气；按揉中脘穴（脐上四横指）每次2-3分钟和胃降逆。
